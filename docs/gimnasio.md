# Gimnasio

Página todavía no construida. Esta nota es la guía para cuando se arme.

## Quiénes la usan

Dos personas, Churrito y Churrita, en el mismo gimnasio. Cada una registra lo suyo el mismo día.

## Qué se registra

- El día
- El nombre de la rutina (por ejemplo: Día de piernas)
- Cada ejercicio: series, kilos y repeticiones

Hoy lo anotan en un chat de WhatsApp, más o menos así:

- Día de piernas
- Sentadilla ×3 - 22.5kg
- Peso muerto x3 - 20kg - 11 repes
